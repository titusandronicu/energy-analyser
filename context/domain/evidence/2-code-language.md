## Where business logic lives

- Push acceptance and idempotency: database function `ingest_push` (hashing, duplicate vs conflict, latest-wins upserts, retention deletes) `...push_ingestion.sql:71-151` and later `create or replace` redefinitions (five copies of the same function body across migrations: `20260925151509`, `20260930081229`, `20261001094118`, `20261001113911`, `evidence`). Payload shape, bounds and capture window: zod contract `contract.ts:214-263`; request size and status codes: `services/ingest.ts:3,49`. So the rule is split three ways (contract, service, SQL).
- Access (owner-only reads, column grants, per-operation policies): database only (policies and grants in `20260923150859`, `20260925123751`, `20260930081229`, `20261001072438`); the app relies on RLS ("RLS returns nothing for non-owners", `recommendation.ts:88`). `evidence`.
- Day-note rules: both database (`check (char_length(text) <= 500 and btrim(text) <> '')`, `20261001072438...sql:16`; date window comment :6) and service (`NOTE_MAX_LENGTH = 500`, `day-notes.ts:9`, `parseNoteForm` :77). Duplicated. `evidence`.
- Freshness, completeness, thresholds, verdict words, Polish copy: TypeScript services (`services/*.ts`), not UI; components "only render" (`period-rating.ts:19-21`, `calendar-view.ts:48` comments). `evidence`.
- Derived measures (self-sufficiency, norm, night grid draw, suspect hour, expected PV share): service functions (`period-rating.ts:112`, `usage-insight.ts:282`, `hourly-usage.ts:150,165`, `live-state.ts:216`). `evidence`.
- Bill-forecast arithmetic: not in this repo; the lab computes it, the app only validates shape and signs and maps it (`contract.ts:96-106`, `bill-forecast.ts:309`). `evidence`.
- Time zone and day boundaries: `format/warsaw-time.ts` (helpers) plus the lab's own `day`/`period` (`contract.ts:54`). `evidence`.
- Domain layer: absent. `src/types.ts` holds row DTOs only; most vocabulary is local to the service that uses it (`Status`, `PeriodRating`, `DayStatus`), and Polish copy is embedded in services (`period-rating.ts:35-62`, `grid-sensor.ts:20`). This matches `0-sources.md` (no separate domain layer). `evidence`.
